# DUO PK Arena V5.0

## 本版完成内容

- 游戏库扩充到 25 个：新增四子棋、6×6 翻转棋、左右爬楼、迷你赛车、像素格斗。
- 每张游戏卡右下角都有独立设置，可分别调整难度、限时/不限时和时长；追踪、跑酷、见缝插针、节奏拔河还有专属选项。
- 随机系列赛使用“洗牌袋”：勾选的游戏先各出现一次，才开始下一轮，且跨轮避免连续重复。
- 统一加入得分浮字、绿色闪光等正反馈；常用游戏支持字母、方向键、数字键和空格操作。
- 2048 固定 4×4 UI，支持限时和不限时；不限时会在双方棋盘都无路可走后结算。
- 多目标追踪增加清晰白边和数字键选择，可设置小球碰撞弹开或互相穿透。
- 节奏拔河整体降速、扩大判定区并缩短输入冷却。
- 恐龙跑酷加入随机障碍间距、二段跳、趴下和高空障碍。
- 见缝插针降低速度并简化 UI；坐标打飞机统一为 5 格十字形，轰炸阶段不限时，先打完者获胜。

## 键盘速查

- 通用：`Esc` 退出菜单，`Space / Enter` 执行主要动作。
- 2048 / 俄罗斯方块：方向键或 `WASD`。
- 数字快判：`A / D` 或 `1 / 2`；色词干扰、多目标追踪、四子棋：数字键。
- 恐龙跑酷：`W / Space` 跳跃，`S` 趴下。
- 爬楼 / 赛车：`A / D` 或左右方向键。
- 像素格斗：`A / D` 移动，`J` 轻拳，`K` 重拳，按住 `L` 防御。

## 部署

覆盖 GitHub 仓库根目录中的 `index.html` 和 `app.js` 后：

```bash
git add .
git commit -m "V5.0 per-game settings and new games"
git push
```

GitHub Pages 会自动重新部署。

若仍遇到 `PERMISSION_DENIED`，请确认粘贴的是本目录 `database.rules.json` 到 **Firebase → Realtime Database → Rules**，不是 Firestore Rules。
