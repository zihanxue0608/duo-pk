# DUO PK Arena V6.1

## 本版完成内容

- 新增架子鼓节奏、数字记忆、小球计数、数字划消、数字连线、经典华容道和单人数独。
- 舒尔特建立独立专区并拆分为六个游戏：静态、左右动态、彩色、蜂窝、反向和转盘；前五种可分别选择 5×5 / 6×6 / 7×7。
- 正误反馈改为操作单元格原地闪绿 / 闪红，不再在画面中央弹出加分文字。
- 掉落射击统一为同色圆靶，靶心使用 `+`，炸弹使用 `×`，移除拖尾。
- 恐龙跑酷改为更宽、更紧凑的横向场地；加入大块障碍、二段跳、趴下专用障碍与可设置生命值。
- 飞机大战也加入生命值；跑酷或飞机生命耗尽会立即结束本局。
- 左右爬楼缩短墙间距离，并与恐龙跑酷、迷你赛车统一采用生命值玩法；生命耗尽立即结束本局。
- 数字记忆确保从第一位开始显示，并按答对位数给予部分分；数字划消会在已选数字上画斜杠。
- 数字连线按“数字—颜色映射 + 指定序列”连接彩色圆点，并实时显示连线路径。
- 华容道与数独修复鼠标交互；数独增加屏幕数字键盘。
- 翻转棋改为标准 8×8 规则；俄罗斯方块取消自动垃圾行与垃圾行技能。
- 像素格斗重做攻击距离、冷却、格挡值、破防硬直、击退和战斗动画。
- 俄罗斯方块、跑酷等使用方向键时会阻止网页滚动。
- 每个限时游戏默认跟随大厅统一时长，也可在独立设置中关闭跟随并指定特别时长。
- 米色 / 深色主题统一调整页面、卡片、按钮、棋盘、输入框与弹窗配色；首页保持简洁版。
- 随机系列赛继续使用“洗牌袋”：选中的游戏先各出现一次，再进入下一轮。

## 键盘速查

- 通用：`Esc` 退出菜单，`Space / Enter` 执行主要动作。
- 2048 / 俄罗斯方块：方向键或 `WASD`。
- 数字快判：`A / D` 或 `1 / 2`；色词干扰、多目标追踪、四子棋：数字键。
- 恐龙跑酷：`W / Space` 跳跃，`S` 趴下。
- 爬楼 / 赛车：`A / D` 或左右方向键。
- 架子鼓：简单/中等使用 `D F J K`，高难度增加 `S L`。
- 华容道：点击选择棋子，使用方向键或 `WASD` 移动。
- 数独：点击空格后按 `1–9`，`Backspace` 清除。
- 像素格斗：`A / D` 移动，`J` 轻拳，`K` 重拳，按住 `L` 防御。

## 部署

覆盖 GitHub 仓库根目录中的 `index.html` 和 `app.js` 后：

```bash
git add .
git commit -m "V6.1 rules, controls and light theme polish"
git push
```

GitHub Pages 会自动重新部署。

若仍遇到 `PERMISSION_DENIED`，请确认粘贴的是本目录 `database.rules.json` 到 **Firebase → Realtime Database → Rules**，不是 Firestore Rules。
